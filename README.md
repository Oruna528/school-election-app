# 学校生徒会選挙アプリ

学校の生徒会選挙を効率的に管理・実施するための投票アプリです。

## 機能

- ✅ 候補者情報の表示
- ✅ オンライン投票
- ✅ リアルタイム開票結果表示
- ✅ 投票者管理（出票率表示）
- ✅ 管理者パネル

## 技術スタック

- **フロントエンド**: React + Next.js
- **スタイリング**: Tailwind CSS
- **言語**: TypeScript

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ブラウザで http://localhost:3000 にアクセス
```
